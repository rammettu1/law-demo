# IPC Code Generator from Voice Input

## Description

This is a demo application that transcribes voice descriptions of events and suggests potentially relevant Indian Penal Code (IPC) sections. It utilizes the Groq API for speech-to-text transcription and for generating IPC section suggestions based on the transcribed text. The application provides a web interface built with Streamlit.

## Features

*   **Voice Input Recording:** Allows users to record audio directly in the browser.
*   **Speech-to-Text Transcription:** Uses the Groq API (Whisper model) to convert recorded audio into text.
*   **IPC Section Suggestion:** Employs the Groq API (Mixtral model) to analyze the transcribed text and suggest relevant IPC sections.
*   **Streamlit Web Interface:** Provides an interactive and user-friendly web application.

## Prerequisites

*   Python (3.8+ recommended)
*   `pip` (Python package installer)
*   A Groq API key. You can obtain one from [GroqCloud](https://console.groq.com/keys).

## Setup and Installation

1.  **Clone the repository (or ensure files are present):**
    If you have a Git repository, clone it. Otherwise, ensure you have the `ipc_voice_app` directory with its contents.
    ```bash
    # Example if cloning:
    # git clone <repository_url>
    # cd <repository_directory>
    ```

2.  **Create and activate a virtual environment (recommended):**
    Open your terminal in the project's root directory (e.g., where `ipc_voice_app` directory is located).
    ```bash
    python3 -m venv .venv
    ```
    Activate the virtual environment:
    *   On macOS and Linux:
        ```bash
        source .venv/bin/activate
        ```
    *   On Windows (Command Prompt):
        ```bash
        .venv\Scripts\activate
        ```
    *   On Windows (PowerShell):
        ```bash
        .venv\Scripts\Activate.ps1
        ```

3.  **Install dependencies:**
    With your virtual environment activated, install the required packages:
    ```bash
    pip install -r ipc_voice_app/requirements.txt
    ```

## Configuration

To use this application, you must set your Groq API key as an environment variable named `GROQ_API_KEY`.

Choose the method appropriate for your operating system:

*   **Linux/macOS (Terminal):**
    Open your terminal and run:
    ```bash
    export GROQ_API_KEY="YOUR_API_KEY_HERE"
    ```
    Replace `"YOUR_API_KEY_HERE"` with your actual Groq API key. To make this permanent, add this line to your shell's configuration file (e.g., `~/.bashrc`, `~/.zshrc`).

*   **Windows (Command Prompt):**
    Open Command Prompt and run:
    ```bash
    set GROQ_API_KEY=YOUR_API_KEY_HERE
    ```
    Replace `YOUR_API_KEY_HERE` with your actual Groq API key. This command sets the variable for the current session. For a more permanent solution, you can set it through the System Properties.

*   **Windows (PowerShell):**
    Open PowerShell and run:
    ```bash
    $env:GROQ_API_KEY="YOUR_API_KEY_HERE"
    ```
    Replace `"YOUR_API_KEY_HERE"` with your actual Groq API key. This sets the variable for the current session. To make it permanent, you can add it to your PowerShell profile.

**Note:** You need to set this environment variable before running the Streamlit application. The application will check for this key upon startup.

## Running the Application

1.  Ensure your `GROQ_API_KEY` environment variable is set (see Configuration section).
2.  If you created a virtual environment, make sure it's activated.
3.  Navigate to the directory containing the `ipc_voice_app` folder (if you are not already in it).
4.  Run the Streamlit application using the following command:

    ```bash
    streamlit run ipc_voice_app/app.py
    ```
    This will typically open the application in your default web browser.
